# Weather

A Windows Phone (Metro) style weather app for Android, with forecasts from AccuWeather. It feeds the
weather live tile on [wp-launcher](https://github.com/Wotworth/wp-launcher)'s Start screen.

- Spec: docs/REQUIREMENTS.md. Status: docs/STATUS.md. For the launcher: docs/LAUNCHER-CHANGES.md.
- Install the APK from the latest release.
- Icons: Fluent UI System Icons (MIT, FLUENT-ICONS-LICENSE.txt). Font: Selawik (OFL, SELAWIK-OFL.txt).
